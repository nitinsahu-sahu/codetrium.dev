# 🚀 NextTech — World-Class Digital Agency & Custom Software Studio

NextTech is a modern, high-performance agency website built for a close-knit team of 4 senior full-stack developers who deliver custom software, Multi-Vendor Marketplaces, MLM Systems, and Flutter mobile applications for clients worldwide.

---

## 🌟 Highlights & Key Features

### 1. **Pages & Routes**
- **Home Page (`/`)**:
  - High-impact Hero section with dynamic code terminal simulator & live sprint status.
  - Interactive **Stats Counter** with animated counters (50+ Projects, 4 Senior Leads, 15+ Countries, 5+ Years).
  - Infinite dual-row **Tech Stack Marquee** (React, Next.js, Node.js, Express, MongoDB, MySQL, Flutter, AWS, Docker, Laravel, WordPress).
  - **Interactive Project Cost & Scope Estimator** with real-time ballpark calculation and direct pre-filled contact form routing.
  - **Featured Products** preview for NextCart Pro (Multi-Vendor Ecom) and NextMatrix (Enterprise MLM).
  - **Why Choose Us** (Direct Senior Access, Rapid Sprints, 100% Code Ownership, Production Architecture).
  - **4-Phase Process Timeline** (Discovery → UI/UX System → Agile Sprints → QA & Cloud Launch).
  - **Client Testimonial Carousel** with 5-star verified international founder reviews.
  - **High-Conversion CTA Banner** with celebration confetti.

- **Services Page (`/services`)**:
  - Detailed architectural breakdowns for Web App Development, Backend APIs, Flutter Mobile, Multi-Vendor Marketplaces, Custom MLM Software, and AWS Cloud/DevOps.
  - Package deliverables checklist, estimated timelines, and starting price benchmarks.
  - Comprehensive Agency & Engagement FAQ accordion.

- **Products Page (`/products`)**:
  - **NextCart Pro**: Turnkey Amazon-style Multi-Vendor Marketplace with Stripe Connect escrow splits, vendor portals, and Flutter companion mobile app.
  - **NextMatrix**: Enterprise High-Concurrency MLM & Binary Compensation Software with interactive D3.js SVG genealogy trees and USDT crypto e-wallets.
  - **NextPulse**: AI-powered SaaS workflow and CRM suite.
  - **Interactive Live Sandbox Demo Modal** allowing visitors to switch between Super-Admin, Merchant, and Customer perspectives with simulated real-time transactions.
  - Commercial License tiers (Starter, Enterprise Multi-Vendor, Custom Whitelabel).

- **Portfolio / Case Studies Page (`/portfolio` & `/work`)**:
  - Category filters (All, Full-Stack Web, Flutter Mobile, Custom Products, Cloud & DevOps).
  - Live client & keyword search bar.
  - Rich Case Study modal with problem statement, architecture diagrams, and verified business metrics ($1.4M GMV, 180ms load speed, 85k+ downloads).

- **About Page (`/about` & `/team`)**:
  - The story behind our 4-engineer studio model.
  - Detailed profiles for the 4 core developer founders (Alex Chen, Marcus Vance, Elena Rostova, David Kumar) with specialties, verified Git commit counts, and 1:1 consultation links.
  - Global footprint breakdown across 15+ countries (US, UK, Germany, UAE, Singapore, Australia, etc.).

- **Contact Page (`/contact` & `/hire`)**:
  - Interactive Project Quote Form with instant validation and URL parameter pre-filling.
  - Instant WhatsApp direct chat button.
  - One-click official email clipboard copying.
  - 2-Hour Response SLA promise and timezone coverage breakdown.

## 🎨 Design System & Theme

- **Primary Colors**: Deep Navy Blue (`#0A2540`), Slate 950 (`#020617`), Surface (`#0F172A`)
- **Accent Colors**: Electric Cyan (`#00D4FF`), Indigo (`#6366F1`), Emerald Green (`#10B981`)
- **Typography**: Sora / Poppins (Headings), Plus Jakarta Sans / Inter (Body), Fira Code (Technical Snippets)
- **Aesthetic**: Modern SaaS/Agency aesthetic (Linear, Vercel, Framer style) with glassmorphism cards, glowing cyan ambient lights, micro-interactions, and dark/light theme switching.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript (Vite)
- **Routing**: React Router DOM v6
- **Styling**: Tailwind CSS v4 with custom glassmorphism and animations
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/agency/nexttech.git

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```
